# Аналитическая станция мониторинга временных рядов (Вариант Б)

Модульный Python-пакет с архитектурой `src-layout` для углубленного анализа 12-суточных временных рядов дебитов скважин. Поддерживает параллельное сглаживание двумя окнами, расчет технологических отклонений, оценку тренда и псевдографическую визуализацию профиля добычи.

## Назначение проекта
Программа предназначена для мониторинга динамики дебита с автоматическим подавлением датчиковых аномалий. Включает симуляцию резкого аварийного всплеска добычи на 8-е сутки для демонстрации робастности медианных оценок по сравнению со средним арифметическим.

## Архитектура пакета
```text
series-advanced/
├── src/
│   └── well_series/
│       ├── __init__.py   # Метаданные пакета
│       ├── config.py     # Константы (SHORT_WINDOW=3, LONG_WINDOW=5)
│       ├── analytics.py  # Математическое расчетное ядро
│       └── main.py       # Интерфейс и построение гистограмм
```

## Инструкция по запуску

1. Убедитесь, что вы находитесь в корне папки `series-advanced`.
2. Настройте переменную путей `PYTHONPATH`, чтобы интерпретатор видел пакет внутри `src`:
   ```powershell
   $env:PYTHONPATH="src"
   ```
3. Запустите пакет как модуль:
   ```bash
   python -m well_series.main
   ```
