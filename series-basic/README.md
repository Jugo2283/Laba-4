# Алгоритмическая обработка числового ряда дебитов скважины (Вариант А)

Консольный скрипт на чистом Python для вычисления базовых статистических показателей суточных замеров дебита нефтяной скважины за 10 суток и их сглаживания методом простой скользящей средней (SMA).

## Назначение проекта
Программа симулирует классическую задачу аналитика нефтепромысла. Реальные замеры дебита всегда содержат случайные колебания («шум»). Данное решение позволяет отфильтровать шумы и наглядно увидеть истинный тренд работы пласта с помощью алгоритмов фильтрации.

## Формулы расчёта

1. **Среднее арифметическое (Mean):**
   \[Mean = \frac{1}{n} \sum_{i=1}^{n} Q_i\]
2. **Медиана (Median):**
   * Если длина \(n\) нечётная: серединный элемент отсортированного ряда.
   * Если длина \(n\) чётная: полусумма двух центральных элементов.
3. **Размах вариации (Range):**
   \[R = Q_{max} - Q_{min}\]
4. **Простая скользящая средняя (SMA) с окном \(k=3\):**
   \[SMA_i = \frac{Q_i + Q_{i-1} + Q_{i-2}}{3}\]

## Инструкция по запуску

1. Убедитесь, что вы находитесь в корне папки `series-basic`.
2. Активируйте виртуальное окружение:
   ```bash
   .\.venv\Scripts\Activate
   ```
3. Запустите скрипт:
   ```bash
   python main.py
   ```
